# Phantom Horizon Studios

**AI agent systems, memory infrastructure, and creative technology.**

Phantom Horizon Studios is an independent studio run by Willie Stewart. Most of the work here lives in the layer between a capable language model and a system that can actually finish a job: tools, persistent memory, retrieval, lifecycle hooks, safe migrations, testing, and the procedures that keep an agent from wandering off halfway through a task.

I use AI-assisted engineering openly. I define the outcome, constraints, and acceptance criteria; direct coding agents through the work; inspect changes and outputs; run tests; diagnose failures; and keep iterating until the evidence matches the goal. The value is not pretending every line was typed by hand. It is knowing how to turn agent output into a working, reviewable system.

## Featured agent-systems work

### [Hindsight Installer MCP](https://github.com/grimmjoww/hindsight-installer-mcp)

An MCP server for managing Hindsight's Postgres extensions and embedding pipeline. It coordinates environment changes, backups, index migration, re-embedding, recall checks, compatibility validation, and rollback through agent-callable tools.

### [VectorChord Windows Port](https://github.com/grimmjoww/vchord-windows-port)

Native Windows build documentation and helper scripts for VectorChord, including a verified Hindsight migration path that works without Docker or WSL2.

### [Hermes Superpowers Plugin](https://github.com/grimmjoww/hermes-superpowers-plugin)

An always-on Hermes Agent plugin that injects procedural discipline before the first model call, exposes the canonical Superpowers skills through Hermes' native tool surface, and preserves upstream provenance.

### [Claude Code + memU](https://github.com/grimmjoww/claude-code-memu)

A Python MCP and lifecycle-hook integration for automatic memory recall and capture with a memU backend.

### [OpenClaw + memU](https://github.com/grimmjoww/openclaw-memu)

A TypeScript memory plugin that connects OpenClaw lifecycle hooks to memU for automatic recall, capture, memory tools, and CLI access. This project is still labeled active development.

## Creative technology

The studio also explores AI-assisted character systems, game tooling, original worlds, and creative workflows. That work shares the same operating philosophy: make the process repeatable, keep the human in control, and leave enough evidence to understand what the system actually did.

## How I work

- Start with the real outcome, not a pile of fashionable tools.
- Break the workflow into clear responsibilities and handoffs.
- Add approval gates where an agent should not act alone.
- Keep changes reviewable with Git, tests, logs, and rollback paths.
- Call experimental work experimental. A clean status label is more useful than fake polish.

My earlier background includes more than 12 years in U.S. military electrical systems, technical troubleshooting, operations, and travel-program administration. That experience still shows up in the way I approach agent systems: trace the fault, follow the evidence, document the change, and verify the result.
