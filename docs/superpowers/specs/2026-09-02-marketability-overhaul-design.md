# Marketability Overhaul Design

**Date:** 2026-09-02

## Purpose

Turn Willie Stewart's Upwork and GitHub presence into one honest, coherent professional story that wins paid AI-agent systems work while preserving Phantom Horizon Studios as the umbrella brand.

## Primary Positioning

Willie is an **AI Agent Systems Specialist** who builds, operates, integrates, and troubleshoots systems that use tools, APIs, MCP, persistent memory, retrieval, repositories, lifecycle hooks, human-approval gates, and multi-step workflows.

The profile must not present him as a generic chatbot builder, a no-code-only automator, or a conventional senior software engineer who manually authors every line. It should accurately describe his AI-assisted engineering workflow: defining goals and constraints, directing coding agents, reviewing changes, running tests, diagnosing failures, managing repositories, and iterating against acceptance evidence.

## Target Clients

Prioritize clients who need one or more of the following:

- MCP servers and tool integrations
- Agent memory, semantic retrieval, or RAG
- Multi-agent workflow design and orchestration
- Agent lifecycle hooks and procedure enforcement
- Prototype or repository rescue
- Windows-native AI infrastructure and integration troubleshooting
- Testing, verification, rollback, and operational documentation

Avoid positioning around low-value generic prompt writing, basic chatbot setup, mass-produced automation, or unsupported claims of enterprise production experience.

## Upwork Profile Design

### Headline

Use a search-friendly headline led by `AI Agent Developer`, followed by the strongest differentiators: MCP, RAG, memory, and automation. Maximum 70 characters.

### Overview

The overview must:

1. Open with the client problem and outcome, not a biography.
2. Explain the difficult execution layer between a capable model and a reliable system.
3. List concrete services in natural language.
4. Describe the AI-assisted engineering workflow honestly.
5. Cite selected public proof without overstating project maturity.
6. Use the military background only as supporting evidence for procedural troubleshooting and operations discipline.
7. End with a specific invitation to share a workflow, repository, or failing system.

### Voice

Professional, direct, warm, technically specific, and human. Remove stock phrases such as `cutting-edge`, `work smarter, not harder`, `leverage the power of AI`, and generic lists of tools without context. Do not sound like a résumé pasted into a sales page.

### Skills

Prioritize skills tied to discoverability and proof: AI Agent Development, Model Context Protocol, Retrieval-Augmented Generation, AI Model Integration, API Integration, Workflow Automation, Large Language Models, Generative AI, Python, JavaScript, TypeScript, GitHub, Software Debugging, Technical Documentation, Prompt Engineering, and Chatbot Development. Keep only skills accepted by Upwork's ontology.

### Experience

Retain the approved Phantom Horizon Studios entry. Add U.S. Navy and U.S. Marine Corps experience using accurate scope and dates, without military jargon that a civilian client cannot interpret.

### Rate and Availability

Keep the launch rate at `$33.33/hour` and availability at `More than 30 hrs/week` until the profile has several completed contracts and reviews.

## GitHub Portfolio Design

### Primary Public Proof

Feature original or materially original work first:

1. `hindsight-installer-mcp`
2. `vchord-windows-port`
3. `hermes-superpowers-plugin`
4. `claude-code-memu`
5. `openclaw-memu`
6. `phantom-horizons-studios`

Forks remain available for research context but must not be presented as original products unless a comparison demonstrates substantial original work.

### Repository Documentation Standard

Each featured repository should make the following answerable within the first screen or two:

- What problem does this solve?
- Who is it for?
- What did Willie build or direct?
- What is the current status?
- What safety, testing, or rollback controls exist?
- How can a client evaluate the work quickly?

Use explicit status labels such as `production-ready`, `validated on stated configuration`, `alpha`, `prototype`, or `active development`. Never convert a prototype into a production claim through marketing language.

### Central Portfolio

Use `phantom-horizons-studios` as the central portfolio index. Agent systems are the primary professional lane; creative AI remains a secondary studio lane. Add links to proof repositories and concise case-study summaries. Do not delete the existing creative website during this phase.

### Change Safety

Make documentation changes on review branches and open pull requests. Do not expose private repositories, secrets, credentials, local paths that reveal sensitive information, or malware-related code. Do not delete, archive, or force-push repositories in this phase.

## Job Search Design

Search for work in three tiers:

1. **Best-fit specialist work:** MCP, agent memory, RAG, tool calling, lifecycle hooks, integrations, prototype rescue.
2. **Good launch work:** focused audits, bug fixes, migration help, setup, documentation, and small integration projects.
3. **Selective adjacent work:** AI technical generalist roles where repository investigation and agent-assisted development are central.

Reject or heavily discount jobs with tiny budgets for expert scope, unclear deliverables, unpaid tests, suspicious external communication, or clients with poor freelancer ratings and weak hiring history.

Score each job on fit, proof match, scope clarity, client quality, budget realism, competition, and time-to-deliver. Proposals must reference one specific client problem and one relevant proof asset; no generic mass applications.

## Success Criteria

The overhaul is successful when:

- Upwork presents a clear specialist headline, humanized overview, relevant skills, and complete supporting experience.
- GitHub has a central professional index and stronger documentation for the most marketable original projects.
- Public claims match repository evidence and project status.
- A reusable job-scoring and proposal workflow exists.
- At least five current jobs are screened and ranked, with tailored application recommendations for the strongest matches.
